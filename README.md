# Hi, I'm Jotimoy 👋

### Embedded Systems & IoT Developer | Robotics Enthusiast | Software Builder

I build practical technology projects that connect hardware, software, and real-world problem solving. My work ranges from ESP32/ESP8266 sensor systems, robotics firmware, and connected dashboards to Flutter applications and intelligent automation tools.

I enjoy turning ideas into working prototypes—from smart monitoring and automation systems to connected devices and user-focused applications.

## What I Build

- **IoT & Embedded Systems:** ESP32, ESP8266, Arduino, sensors, OLED displays, MQTT, LoRa, Bluetooth, and web dashboards
- **Robotics:** RC cars, line followers, soccer bots, servo-based systems, BLE air mouse, and interactive robots
- **Smart Monitoring:** Water level, weather, health, heat-stress, river-water quality, incubator, and environmental monitoring
- **Applications:** Flutter mobile apps, Kotlin Android apps, TypeScript/React web apps, PHP systems, and Java desktop applications
- **Computer Vision & AI:** OpenCV tools, barcode reading, face recognition, and emotion detection
- **Software Engineering:** Requirements engineering, management systems, academic projects, and structured project documentation
